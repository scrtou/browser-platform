# DEV-154 · root 安装误触镜像启动配置

状态：处理中。关联 [R6AX](../work-items/R6AX-2026-10-03-v1-release.md)。

第二次新安装已通过独立 UID 控制器启动及控制身份创建，但内置包准备返回 `ENVIRONMENT_UNAVAILABLE OSError`。固定 Camoufox 的镜像校验以调用者 UID 执行；镜像内 `environment.py verify` 在 UID 0 时还会配置桌面启动文件。安装器以 root 调用校验且校验容器为只读，误触写入路径。原 `/srv/bp-r6ax-fresh2` 与失败日志保留，内置镜像/报告没有修改。

选择让安装器在完成私有文件所属设置后，以目标非 root 服务用户调用内置准备器，与生产任务执行器保持相同身份。保留只读、无网络、无能力的校验容器门槛，不通过加写权限或跳过镜像校验绕过。第三个新根须实际安装、后续全流程验收通过后才能收尾。
