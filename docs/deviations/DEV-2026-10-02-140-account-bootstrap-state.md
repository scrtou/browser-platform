# DEV-140 · 清空测试账号后缺少显式初始化状态

状态：已解决（R6AV部署与最终验收通过）。关联：[R6AV](../work-items/R6AV-2026-10-02-test-data-cleanup.md)。

用户要求删除唯一owner管理员，1.0不预置账号并以CLI创建首位管理员。现有账号注册表要求至少一条账号，缺失表也导致Adapter启动失败；因此直接删除owner无法维持明确的初始化入口。

选择修复实现：增加显式、版本化的“等待初始化”注册表状态，仅允许零账号；普通旧版本空表/缺失/损坏继续拒绝。CLI创建首位管理员后退出该状态，非管理员初始化拒绝，UI/API不能绕过最后管理员和当前账号删除保护。清理时仅在服务锁与已核实目标范围下写入该显式状态；不提供通用线上清空账号接口。

验证包含状态格式拒绝、CLI并发/已有账号保护、初始化前登录拒绝和初始化后管理登录。实际部署及清理完成前不标为解决。

最终结果：[R6AV验收](../../infra/sealskin/r6av-test-cleanup-acceptance-2026-10-02.md)通过；代码回归、部署、实际数据清理及独立程序留存均完成。以上早期未完成状态保留过程时点，原失败日志未改写。
