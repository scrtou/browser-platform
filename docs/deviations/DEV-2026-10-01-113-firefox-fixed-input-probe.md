# DEV-113 · Firefox 固定小窗口输入验收失败

状态：已解决，R6S服务器验收并部署。关联 [R6S](../work-items/R6S-2026-10-01-shared-display-templates.md)。

固定 Firefox 首次完整验收通过浏览器 API、存储与网络探针，screen/window 符合1280×900 / 1000×800，但真实 X11 点击标题断言失败，报告零份已完成观察。原断言没有记录目标/实际标题和点击时几何，尚不能区分运行端与探针时序问题。

保留失败产物、Home、探针与关闭日志；使用同镜像/精确产物的独立小窗口诊断补充坐标、窗口状态和截图。只在事实明确后修复，再用新作业跑完整原场景，不以已有自动模式通过替代固定输入。

精确产物诊断的三个实际点击和文本输入均成功，窗口位置0,0、1000×800；加入采样开销后标题响应可观察，原固定100毫秒等待不足以作为异步点击完成条件。改为最多3秒等待真实标题回显，超时仍失败，并保存点击前几何。诊断同时发现固定 Firefox 的 XWD 是24 bits-per-pixel、每行5120字节，原截图工具只接受32位；改为按真实24/32位像素宽度与行跨度解码，并以已知彩色像素/行填充及截断输入测试验证，不修改浏览器观测或渲染设置。新作业仍须通过完整重建和恢复。

最终验证（2026-10-01）：修正异步等待及24/32位XWD解码后，Firefox固定新作业22份观察与恢复通过，截图已人工核对；自动组合及同Home显示切换通过，最终限定发布完成。 证据根为 `infra/sealskin/runtime/r6s-shared-display-20261001/`，见[R6S最终验收](../../infra/sealskin/r6s-shared-display-acceptance-2026-10-01.md)。
