# DEV-129 · Relay 固定 APK 版本已退出当前镜像源

状态：已解决并部署。工作项：[R7G1](../work-items/R7G1-2026-10-02-dynamic-deployment.md)。

预期：固定 Relay 源码与 Dockerfile 可构建新候选。事实：2026-10-02 重建时 Alpine 3.23 源仅提供 Python 3.12.15-r0，原固定 3.12.14-r0 被拒绝；旧 R7G 镜像已不在本机。失败证据保留于 R7G1 私有 relay-build.log，未更改生产。

选择修复构建：显式更新 Python 补丁锁为 3.12.15-r0，其他包与基础镜像摘要保持；完整 Relay test/vet、实际包版本与动态/静态 QA 重新核对。候选镜像随输入摘要取得新标签，不覆写旧标签。恢复交付同时保存精确新镜像，离线恢复不依赖滚动软件源。

后续证据与最终状态随 R7G1 收尾更新；不把联网源码复建等同永久可复建，APK 仓库留存限制写入组件文档。

结果：新锁镜像实际版本、Go test/vet、52 Guard QA、22 组集成及保护发布通过；精确镜像冷导入独立机器并校验，构建失败证据保留。见[R7G1 验收](../../infra/sealskin/r7g1-deployment-acceptance-2026-10-02.md)。
