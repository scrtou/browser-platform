状态：已解决（本轮临时维护范围）。日期：2026-09-30。工作项：[R7G](../work-items/R7G-2026-09-27-dynamic-upstream-hot-switch.md)。

预期：复用此前已授权的专用 QA DNS 与两个公网端点，保持原 DNS 区域和生产浏览器不变。

实测：原 QA 权威容器为 stopped；在核对精确镜像、标签和只读配置挂载后启动。本机 UDP/TCP 可读到新 SOA 和 QA A 记录，两台公网代理 HTTPS 可达；外部 DNS 查询超时，公共递归返回 SERVFAIL。只读主机规则显示 IPv4 INPUT 默认 drop，VPS-BASELINE 的无条件 return 位于 UDP 53 accept 之前，且无有效 IPv4 TCP 53 放行。历史端口开放不能视为当前入站仍可用。

处理：不重写现有链、持久化配置或旧规则，不把服务启动/本机查询记作公网通过。准备仅限 eth0、目标 23.19.231.152、UDP/TCP 53 的两条临时规则，使用本次唯一注释，校验后按精确 handle 回收。此操作改变主机入站访问，需区分先前资源复用授权与本轮“不部署生产”的维护范围；确认前只做独立 QA 和发布准备。

证据：忽略目录 `infra/sealskin/runtime/r7g-public-20260930/` 保存权威原状态/区域变更、本机回答、远端超时、完整只读规则和候选规则。原阶段的 DNS/端点验收记录保持历史范围，本轮公网轮换尚未执行。结束时只删除本轮名称、递增 serial、恢复权威原停止状态，并精确停止/清理本轮公网进程。
