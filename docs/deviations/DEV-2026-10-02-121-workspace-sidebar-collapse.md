# DEV-121 · 侧栏折叠布局与键盘可达性

状态：已解决并部署。[R6AB](../work-items/R6AB-2026-10-02-workspace-navigation.md)。

审查agy首版源码发现：桌面收起同时设置width:0和margin-left:-230px，造成主区偏移；手机隐藏侧栏只使用transform，仍允许键盘进入不可见链接；首页和管理区的手机断点不一致。选择修复实现，统一768px断点，折叠移出布局且隐藏不可见控件，增强展开状态与焦点返回。首页nonce生成失败回退也应明确失败处理。独立候选保留模型原稿，修复后通过真实浏览器三宽度、侧栏键盘与布局核对，不能降低验收要求。

主流程同时发现并修复管理header未闭合、指纹页被条件排除导致侧栏键盘脚本缺失。隐藏侧栏使用visibility及增强inert，手机展开侧栏时限制焦点，收起后恢复触发按钮；首页随机nonce失败明确返回错误。两套完整Go test/vet及69状态真实浏览器检查通过，三宽度收起时主区位于视口内、隐藏链接不可聚焦、Tab循环/Esc/详情与无脚本路径均通过。[R6AB验收](../../infra/sealskin/r6ab-workspace-ui-acceptance-2026-10-02.md)保留模型原稿及失败记录。
