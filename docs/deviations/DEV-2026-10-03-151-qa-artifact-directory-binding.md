# DEV-151 · QA收集器误把产物ID当成作业目录名

状态：已完成本项处理、最终验收及部署（2026-10-03）。关联[R6AW](../work-items/R6AW-2026-10-02-protected-builtins.md)。

自动Camoufox正常生成后的产物ID可带`-artifact-1`后缀，实际文件仍位于请求`spec.id`对应的作业目录；目录中的application mount记录了正确路径。内置分片汇总器、远端收集脚本与本机已验收Home清理器错误地用目录条目的产物ID拼接路径。清理器在找不到报告时安全停止，没有删除未验收Home；同一假设会阻断最终汇总。生成器和原accepted报告没有错误，不能为适应收集器改写它们。

处理：核对请求、实际mount、固定QA根、产物/报告摘要，按请求目录读取，汇总输出可用产物ID建立新的规范目录并重绑定mount。旧报告字节、原目录与失败证据不变。拒绝越界/不匹配的mount，不以任意路径回退查找。用已有真实accepted自动Camoufox进行正向与路径混配拒绝验证，再完成最终24包检查。已验收Home清理仍必须核对报告绑定和所有容器挂载。

同时核对原生成器的身份契约：固定Camoufox目录使用请求spec ID，自动Camoufox目录使用顶层artifact ID（spec ID加`-artifact-1`）；文件都在请求目录。包校验器保留这一区别，通过完整compose对比继续校验两者关系，不能要求二者强行相等。已有16组合的32份真实产物/报告路径与摘要通过核对，派生产物ID场景及错误mount/父目录拒绝通过；最终24包仍待完成。

最终复核：R6AW v6完整24组合、四份固定Camoufox桌面补验、真实包/安装拒绝和实际部署均通过，原失败及早期诊断保持各自范围，详见[R6AW最终验收](../../infra/sealskin/r6aw-builtins-acceptance-2026-10-03.md)。本条不扩大供应商或其他主机性能的验证范围。
