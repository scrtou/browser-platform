# DEV-068 · 统一代理探针结果缺少时间

状态：已修复（R7E 未部署候选）。发现日期：2026-09-23。关联：[R7E 工作项](../work-items/R7E-2026-09-23-management-network-home-ui.md)。

## 偏差与影响

[R7 方案](../browser-workspace-plan.md)要求网络代理 Tab 展示探针状态和时间。R7C 目录只保存 `probe_code`、创建时间及成功验收时间；失败探针没有结果时间。因此页面不能准确显示失败探针发生时间，使用创建时间会误导管理员。

## 处理

在不可变代理修订记录及脱敏摘要中增加可选 `probe_at`。探针成功和失败时均在目录原子写入 UTC 时间；凭据导入失败和草稿过期不伪装为探针。页面只在有实际探针结果时显示码与时间。旧目录缺少该可选字段时仍可读取，旧失败记录不补造时间。验证见 [R7E 验收](../../infra/sealskin/r7e-management-network-home-acceptance-2026-09-23.md)。
