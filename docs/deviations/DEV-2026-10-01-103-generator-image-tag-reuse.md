# DEV-103 · 重建相同输入标签导致旧 QA 镜像 ID 不可解析

状态：已解决并部署。关联 [R6R](../work-items/R6R-2026-10-01-multi-engine-generation.md)。

事实：新构建器按输入摘要命名标签，却对已存在的同名标签再次执行 build。当前 Docker/containerd 对 attestation 生成新 manifest，标签移动后两份早期失败诊断所引用的旧 ID 不再可 inspect，下一份诊断的 Fixture 在浏览器启动前失败。生产基础镜像标签、运行容器和现有 accepted 产物未改变。

预期：产物引用的完整镜像保持可解析，相同已验证输入复用不可变镜像，不移动其标签。

处理：构建器增加输入摘要标签，已存在时校验摘要及基线并直接复用，不重建或覆盖。早期失败输入与日志保留，并明确旧诊断 ID 的不可解析事实；正式验收改用修复后的不可变镜像。失败 Fixture 的两个空 QA 网络按精确身份清理。

结果：R6R最终固定镜像/源码的相关完整验收与拒绝/恢复检查通过，限定部署完成；详见[R6R验收](../../infra/sealskin/r6r-multi-engine-acceptance-2026-10-01.md)。原失败证据保留，能力边界未降低。
