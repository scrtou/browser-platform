# DEV-104 · 原生引擎窗口能力边界

状态：已解决并部署。关联 [R6R](../work-items/R6R-2026-10-01-multi-engine-generation.md)。

核对固定镜像发现 Openbox 的通用及 Chromium 规则均为最大化；原生 Firefox 也继承最大化。小于屏幕的窗口不能按声明实现。完成条件要求不支持参数明确拒绝，不能等生成后才发现不匹配。

处理：本次新增的 Chromix/Firefox 生成器只接受窗口等于屏幕的固定显示模板，由 Adapter 入队前和 runner 读取请求时双重拒绝不等尺寸。Camoufox 现有窗口契约保留。支持独立原生窗口尺寸属于后续能力扩展，未作为已实现能力发布。更新界面说明和组件契约，并验证拒绝路径。

结果：R6R最终固定镜像/源码的相关完整验收与拒绝/恢复检查通过，限定部署完成；详见[R6R验收](../../infra/sealskin/r6r-multi-engine-acceptance-2026-10-01.md)。原失败证据保留，能力边界未降低。
