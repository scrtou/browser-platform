# DEV-100 · 有数据的模板组合表格在窄窗口溢出

状态：已解决并随 R6Q 部署。关联 [R6Q](../work-items/R6Q-2026-10-01-engine-neutral-fingerprint-templates.md)。

预期：通用指纹列表中的引擎/显示选择与提交按钮在 390/768/1280 窗口均有标签、可见且可操作。

事实：R6Q Linux Chromium 使用带指纹行的真实服务器 HTML 检查时，控件边界断言失败。R6P 页面证据使用空列表，未覆盖新增组合行的数据状态，不能据旧六组页面 PASS 宣称此场景通过。原失败输出已记录；私有证据根为 `infra/sealskin/runtime/r6q-engine-neutral-20261001/ui-final/`。

处理选择：修复实现。组合列表补充窄窗口布局并重跑相同边界、标签、键盘和截图检查，不降低验收条件。更新 UI 说明、R6Q 验收与工作项。

结果：窄屏将组合表格按行显示，选择控件采用纵向排列。相同六组检查全部 PASS，390px 截图人工复核通过；修复前 HTML/截图和失败回执保留在私有证据根。
