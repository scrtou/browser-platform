# DEV-146 · 内置安装包的关联校验缺口

状态：已完成本项处理、最终验收及部署（2026-10-03）。关联[R6AW](../work-items/R6AW-2026-10-02-protected-builtins.md)。

代码复核发现，候选安装器验证了清单摘要、24项来源矩阵和验收报告，但未逐项关联来源记录、兼容三元组、镜像目标和设备缓存。文件整体摘要可检测传输变化，不能替代安装前的业务关联校验；单独更新清单后，混配内容仍可能进入准备目录。工具尚未部署，也未导出正式24组合包。

处理：增加导出/安装共用的语义校验，逐项检查唯一ID与兼容关系、规定来源、固定目标、显示参数、完整报告和缓存设备一致性；重复安装保留冲突拒绝。用最终真实包执行正向、重打摘要后的混配拒绝与幂等检查，原始24份报告保持不变。证据保存在R6AW私有根，未通过前不安装。

最终复核：R6AW v6完整24组合、四份固定Camoufox桌面补验、真实包/安装拒绝和实际部署均通过，原失败及早期诊断保持各自范围，详见[R6AW最终验收](../../infra/sealskin/r6aw-builtins-acceptance-2026-10-03.md)。本条不扩大供应商或其他主机性能的验证范围。
