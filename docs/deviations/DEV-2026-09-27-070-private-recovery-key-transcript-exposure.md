## 预期

备份及发布复核只读取管理员恢复材料的权限、摘要和结构，不输出私钥内容。私钥只保存在被忽略的私有运行目录与加密备份中。

## 实际事实与影响

R7F 查询旧 R6F 备份元数据时错误地完整读取了一份管理员恢复 JSON，使其中的私钥进入本次私有操作会话输出。内容没有写入 Git、公开文档或发布候选，但该密钥不能再视为未暴露。当前 Adapter 管理调用使用独立的 `profile-admin` 身份，因此该事件没有改变正在运行的 Personal generation 或阻断本次正常停止/备份。

## 处理决定

- 后续检查只输出恢复材料的字段名、权限和摘要，不再读取其值。
- R7F 收尾前撤销或轮换受影响的旧 `admin` 恢复身份，并验证 `profile-admin`、入口账号、Session 和 Profile 生命周期仍正常；新的恢复材料只写入私有目录。
- 公开记录不保存旧值、新值、私钥摘要或可用于定位授权会话的参数。

## 验证与收尾条件

- 新 `admin` 恢复身份与生产 `profile-admin` 加密管理调用通过；2026-09-30 已补齐原归档旧 `admin` 身份返回 401 的直接证据。
- 新的离线恢复材料权限、备份收集和隔离 restore 通过，命令输出不含私钥正文。
