# DEV-116 · 显示模板数字输入样式缺失

状态：已解决（R6V 验收并部署）。关联 [工作项](../work-items/R6V-2026-10-01-fingerprint-data-ui.md)。

设计要求输入控件具有一致高度、间距和窄屏可达性。R6V 首次三宽度交互通过后，人工检查 768 宽截图发现屏幕/窗口数字输入未匹配既有 input[type=text/url/password] 样式，表现为矮小的原生输入框。自动交互通过不代表视觉要求通过。

处理：将指纹数据功能内的 number 输入加入共用控件样式，限定作用范围；在真实浏览器检查数字输入高度并复查截图。保留原截图于私有 `ui-final/`，最终结果另存新目录，未降低视觉要求。

最终回环HTTP真实15次提交/303/GET、三宽度、键盘/历史导航/禁用脚本通过；最终截图及数字输入高度核对通过，见[R6V验收](../../infra/sealskin/r6v-fingerprint-data-acceptance-2026-10-01.md)。
