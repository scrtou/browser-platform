# DEV-123 · 弹窗排版与手机侧栏键盘冲突

关联：[R6AE](../work-items/R6AE-2026-10-02-dialog-layout-password.md)。状态：已解决，三宽度UI与Go验证通过并部署。

用户要求修改密码弹窗和整齐的管理弹窗。R6AD仍使用独立修改密码页面，指纹删除summary带展开标记；记录弹窗直接搬入旧卡片，网络字段靠右且存在多层折叠。新弹窗在手机侧栏打开时，旧document键盘监听还会抢先阻止Escape的原生关闭。

处理：按授权修复实现，复用agy生成的页签和样式组件，再按现有表单结构调整。密码入口渐进增强为共享dialog，记录操作分功能页签，删除改直接button，网络表单改整齐网格。侧栏快捷键在dialog打开时让位。密码最低4字节是用户明确修订，不降低其他认证和验收条件。

验证：独立候选/工作树Go测试、三种宽度浏览器自动化、截图检查；手机弹窗关闭和焦点归位单独覆盖。敏感材料只保存私有runtime。最终结果见工作项与验收报告。
