# DEV-169 · 公网HTTP端口漏检

状态：已解决（源码与隔离验证，整机安装未复测）。关联[R6BA](../work-items/R6BA-2026-10-03-deployment-config.md)。

安装文档要求公开80/443可用；Caddy生产自动HTTPS使用80进行跳转/HTTP证书验证，但安装器前置bind检查只有三个后台端口与443。80被占用时可能到创建用户、配置和启动控制器后才失败，与安装前检查资源冲突的目标不符。

选择修复：生产模式前置检查80及443的公网绑定；QA私有TLS禁用自动HTTPS，仅检查自己的回环端口，不占用公网80。保持已有资源/失败目录保留行为，不在安装器中停止其他服务或自动抢占端口。

验证：安装器完整文件生成路径的系统调用替身测试证明80冲突在root创建前拒绝；公网80/443与QA仅回环的监听集合测试通过。错误明确显示 `PORT_UNAVAILABLE: 地址:端口`。本次未在生产抢占端口；独立机SSH连接超时，真实整机复测未完成，见[R6BA验收](../acceptance/r6ba-deployment-config-2026-10-03.md)。

端口核对还补充显式 `https://域名:443` 的支持：规范化为浏览器Origin省略默认端口的形式；自定义生产公网端口仍拒绝，防止把QA端口能力写成生产支持。
