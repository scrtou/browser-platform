## 交互与数据

- URL、字段名、表单边界、权限、近期密码确认、CSRF和服务端验证保持。统计只读取现有页面数据，不增加探测、启动或查询外部系统的副作用。
- 健康统计排除过期和阻塞；需要关注包含不可用、过期、阻塞和已观测非healthy。代理可用统计排除过期修订；数字仅代表当前返回列表，不虚构全局总量。
- 搜索仅过滤当前浏览器/代理/账号列表，显示匹配数；清空后恢复。无脚本时不显示无效搜索框。
- dialog保留明确名称、Esc/取消关闭、Tab/Shift+Tab焦点循环和关闭后焦点恢复。延迟close事件不得抢走用户已经移到其他控件的焦点。
- 无脚本或不支持dialog时，新增表单以内联方式呈现；原新增浏览器的联动依赖与禁用脚本提示保持。其他表单和侧栏导航仍可提交/跳转。
- 所有脚本使用当前请求nonce。默认无新增能力的浏览器页仍无脚本；有增强交互的管理页使用已有严格CSP，不增加内联事件或外部资源。
- 删除确认、浏览器引用保护、运行中配置拒绝、原子幂等处理和未完成操作保留不变。界面不能代替后端鉴权。

主要修改 `adapter/internal/access/gateway.go` 的认证/首页模板、`adapter/internal/httpapi/manage.go` 的管理模板及只读统计。模型首轮候选的过期健康统计、未接通搜索/弹窗和键盘问题由主流程审查修正，见 [DEV-120](deviations/DEV-2026-10-02-120-reference-ui-health-summary.md)。不把agy进程退出或返回SUCCESS等同于实现通过。

## R6AB · 统一导航与只读详情（已部署）

用户2026-10-02反馈修订：一级“管理面板”只展开/收回四个二级菜单，不再进入独立落地页；首页和管理页共享相同品牌、导航层级和侧栏折叠交互。二级与指纹数据子功能保留原服务端GET路由、地址栏及前进/后退语义，内容显示在主工作区，不使用嵌套框架。

侧栏允许展开/收回，窄屏必须保留可达的恢复入口。首页列表显示名称、实际状态、网络配置与两个操作。详情只读取本次页面授权摘要中的健康/原因码、网络、浏览器模板、指纹模板、显示模板和采样时间，不发起探测或启动。过期健康明确未知，不可用/未观测不能显示healthy。弹窗具备名称、关闭按钮、Esc及焦点恢复，无脚本保留可展开详情。

首页为上述交互增加每请求随机nonce脚本，CSP只放行该nonce；认证页原CSP保持不变。此修订替代上文“首页无脚本”与首页卡片组织，具体完成状态以[R6AB工作项](work-items/R6AB-2026-10-02-workspace-navigation.md)及[验收](../infra/sealskin/r6ab-workspace-ui-acceptance-2026-10-02.md)为准。

## R6AC · 管理内容列表化（已部署）

四个管理二级功能统一列表表头、行间距和操作区；浏览器、指纹来源、自定义/内置显示及已验收组合从卡片改为表格，代理、账号和任务沿用列表并统一样式。浏览器详细配置与原管理表单、代理/账号较长操作以“详情 / 管理”渐进增强弹窗呈现，默认行不展开全部配置；指纹数据的新增/验收表单折叠。无脚本保留原生details内容和全部表单，动态增强移动表单而不复制，保证控件ID唯一和原POST字段不变。手机表格在自身容器内滚动，页面不整体溢出。见[R6AC工作项](work-items/R6AC-2026-10-02-management-lists.md)。

## R6AD · 指纹数据操作弹窗（已部署）

用户指出R6AC的指纹数据新建/删除仍为行内展开，与统一弹窗体验不一致。本轮把创建指纹、创建显示、组合验收和删除指纹/显示/组合/任务全部接入既有记录dialog组件。新建明确标题，删除明确对象，提供关闭/取消/Esc与焦点恢复。原details只作为无脚本或不支持dialog时的回退，不再是正常脚本环境中的交互。只移动原表单，不复制或改字段、默认值、权限及引用删除保护。见[R6AD](work-items/R6AD-2026-10-02-fingerprint-dialogs.md)。

## R6AL · 工作区网络列

工作区概览在状态与操作之间显示只读“网络”列，来自既有授权 `HomeCard.Network`：`direct` 为直连、`proxy_required` 为代理网络、`managed` 为受管理网络、`unmanaged` 为未受管理、`legacy` 为旧版网络。其他非空值转义显示；空值为未登记，摘要不可用时明确提示。原 `NetworkIssue` 以“需要处理”标示。该列表示配置模式，不代表实时出网健康；健康与原因码仍在详情中查看。

保留现有表格、操作按钮、详情与无脚本路径；窄屏只允许表格容器内部横向滚动。实现与上线状态见 [R6AL 工作项](work-items/R6AL-2026-10-02-workspace-network.md)。

## R6AM · 显示实际代理名称

用户明确要求识别实际代理，本修订替代 R6AL 对 `proxy_required` 仅显示“代理网络”的规则：从当前浏览器绑定的代理目录 ID/revision 读取 `Label`，列表直接显示该名称，详情显示名称及原网络模式。直连仍为“直连”；没有名称时明确显示“代理名称不可用”，不以主机地址推测名称。保留异常提示、长文字换行和原列表布局。

名称由服务端读取内存中的精确目录绑定，禁用但仍被使用的修订仍可显示；只传递名称，不向首页提供代理地址、凭据或未授权代理目录。健康缓存与授权边界保持。状态见 [R6AM 工作项](work-items/R6AM-2026-10-02-workspace-proxy-name.md)。
