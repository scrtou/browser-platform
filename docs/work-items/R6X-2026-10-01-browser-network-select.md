# R6X · 单个浏览器网络下拉选择

状态：已收尾并部署（2026-10-01）；前项 R6W 已收尾。本项仅改已有浏览器卡片的网络配置交互。

## 范围与代码核对

`managePage` 从环境摘要和 Profile Records 取得当前绑定，代理目录筛选 accepted、未过期且对该浏览器授权的修订。原模板为 DIRECT 及每个代理分别渲染表单，占用空间。改成一个网络下拉框、一个操作标识和一个应用按钮，默认选中当前绑定；当前绑定不在可选目录时使用不可提交的占位，不自动选中其他网络。新增浏览器与顶级代理目录保持。

统一提交使用 `manageBrowser` → 选择解析 → 原 `manageNetwork` / `manageNetworkProfileBind` → `SetBrowserManagedDirect` / `BindNetworkProfile`。后两者仍持有生命周期锁并检查 stopped/资源为零，再由控制器追加策略和修改应用/目录；不隐式停止。管理员/manage、CSRF/Origin、近期密码、revision、幂等键和代理授权不变，不增加已有浏览器复用凭据授权能力。

现有未提交改动全部保留。候选基于 R6W 冻结 Adapter 源，仅合入本项 HTTP/UI 文件；不发布 R6I/R7G，不修改控制器、runner、Home、Session、生产目录。私有证据：`infra/sealskin/runtime/r6x-network-select-20261001/`。

## 完成条件与验证

1. 每张浏览器卡片网络区仅一个下拉表单和应用按钮；当前 DIRECT/代理准确回显，缺失/禁用/未授权绑定显示占位；运行时提示先安全关闭。
2. 服务端独立解析 DIRECT/代理修订，不依赖 JS；非法/重复字段、能力关闭和授权拒绝不产生应用调用；原忙碌/revision 错误提示保留。
3. Go test/vet、隔离渲染/表单检查通过。最小冻结候选验证后只更新 Adapter，核对运行摘要、ready 与原配置/容器/会话/凭据/作业/runner保持。
4. 更新 UI 设计、管理规格、Adapter README、用户与运维说明、验收索引、导航/进度/计划、本项及偏差记录。目标客户端反馈单列，不冒称已测。
