# R2B · 旧 Firefox 加密备份的真实浏览器恢复

状态：已收尾。开始日期：2026-09-15。结束日期：2026-09-15。

## 目标与范围

承接已收尾的 [R2A](R2A-2026-09-15-legacy-backup-preparation.md) 和 [R5E](R5E-2026-09-15-release-combination.md)，补齐 [R2](../roadmap.md#r2) 维护前的旧格式浏览器证据。在独立 QA 控制器与 Home 使用生产旧 Firefox 的精确镜像，写入持久 Cookie、localStorage 和 IndexedDB，正常关闭后加密备份，再从新私有根恢复，由真实浏览器读取。

本项只验证 QA 数据及旧格式恢复边界。生产 Home、四个容器、会话绑定和五份配置保持；不部署候选、不退出生产浏览器、不重启主机。真实 Home、linger、Debian 13、目标 Mac 和实际切换仍分别归 R2/R4B。

## 阅读与代码核对

已核对导航、进度、计划、工作流程、R2/R2A/R4B/R5E、旧格式验收及恢复操作说明。调用链为 Adapter 固定入口/控制 socket → SealSkin 生命周期及 Docker Home 挂载 → `secure-backup.py snapshot-legacy/create-legacy/verify/restore` → 新控制器/新代次。R2A 的真实 age/CLI 检查没有真实浏览器；R5E 是 C3/r7/Store 格式，不能替代本项旧镜像证据。

复用固定旧控制 payload、QA Docker 代理和加密 API 客户端；核对镜像、启动方式与 QA 观测标志。旧镜像不具备 r6/r7 的停止保证，须记录实际正常关闭方法和数据落盘证据，不能把强制终止视为正常退出。已有工作区及 index 保留。

## 完成条件与验证

- 精确旧 Firefox 镜像的真实进程在独立 Home 写入三类持久数据；记录显示模式和 QA 调试差异。
- 运行中备份拒绝；正常关闭并经生命周期释放后创建真实 age 旧格式归档。
- 完整认证、离线恢复、新根身份与应用路径核对后，原 QA 源退出占用，新 QA 控制器/新代次读回三类数据。
- 无 Store、密封 Session 或伪造环境产物；离线标记不被误记为生产可激活。已有目标拒绝及错误 identity 检查保留明确证据。
- QA 容器、临时网络/进程/tmpfs 清理；生产容器及配置/绑定摘要保持。
- 更新组件、恢复说明、设计/规格、父 R2、验收索引、进度/计划及本工作项；完成链接、语法、敏感扫描与改动核对。

## 实施与偏差

真实旧镜像已写入/读回三类数据；正常关闭确认、旧格式真实 age 往返、新私有根浏览器读回、错误 identity/已有目标拒绝和 QA 清理均通过。首次 QA 观测用 root 读取 abc 进程环境被内核拒绝，改为同 UID 后通过，失败日志保留。首次加密备份被残留 Wayland socket 阻断，已登记并解决 [DEV-039](../deviations/DEV-2026-09-15-039-legacy-wayland-backup-socket.md)。
