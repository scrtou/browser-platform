# R5B · 受控 Secret Store、撤销与加密恢复

状态：已收尾（候选代码与隔离 QA，未部署生产）。开始日期：2026-09-14。结束日期：2026-09-14。

## 目标与范围

- 对应 [R5](../roadmap.md#r5)，前置 [R5A](R5A-2026-09-14-proxy-protocols.md) 已完成代码、验收、清理及文档收尾。本项继续交付候选代码和隔离 QA，不部署生产，不停止真实浏览器或复制真实 Home。
- 实现一种受控 FileSecretStore：配置只引用 `secret://<id>/username/<version>` 与对应 password 引用，拒绝任意路径、远程 URL、混合版本、未授权主体。凭据版本不可覆盖，授权绑定 SealSkin 用户、Profile、Home 和应用；保留旧策略摘要与旧 generation 的停止兼容。
- 持久存储用独立主密钥进行认证加密；密钥不进入普通配置、镜像、Worker 或 Home。控制端验证授权后只向对应 generation 的 tmpfs 目录写入临时凭据，Relay 只读挂载该目录。
- 增加 Relay 的有界凭据租约检查：撤销、租约丢失或损坏时关闭监听和已有隧道，保持原 Guard 阻断。撤销先持久化禁用、阻止并发启动/恢复并阻断出站，再走既有 Home 锁和正常停止；失败保留占用与可重试记录，不能报告未证明的清理成功。
- 常规轮换建立新凭据版本及策略修订，旧代次保持原引用，完成停止后才能切换。停止删除临时材料；恢复须重新授权并在 Relay 启动前重建材料，禁用/缺失密钥不降级。
- 提供加密备份/恢复路径，使用独立恢复密钥及标准加密工具，包含 QA Home、配置/固定产物、Secret Store 和必要解密材料。只在隔离环境恢复，不覆盖现有状态或撤销记录；真实 Home 演练仍归 R2。
- S01/S06 在本项覆盖 Secret Store、Relay、生命周期与备份的新路径；Note、最终用户入口与全层 Session 授权/脱敏仍由 R5D 完成。DIRECT、公开 DNS/TTL 和实时一致性归 R5C。全部父验收及发布条件保留。

## 实施与偏差

[DEV-009](../deviations/DEV-2026-09-14-009-backup-key-paths.md) 记录旧备份 SSL 路径和新草稿恢复密钥覆盖的缺口；本项修复并实际验证，保留原 R2 证据范围。

按上述范围实施。计划中的未实现能力记录为本项待办；若发现实现或配置违反仍有效的契约，立即在 `docs/deviations/` 登记并链接，不降低验收条件。

最终已实现加密版本存储、四维授权、tmpfs 代次材料、Relay 租约、撤销与恢复锁。控制器启动及每两秒重新授权，主密钥丢失或提交撤销后中断均阻断出站。备份使用 age v1.2.1，包含真实 Adapter journal、服务/管理员恢复材料、固定产物及验收文件；缺失必要材料拒绝。恢复先在 tmpfs 完整验证，再写新目录并保持禁用。启用恢复前要求源/目标存储均无容器挂载，持有存储锁合并最新撤销，并在解除恢复锁前持久化启用记录；中断可重试。Home 硬链接以独立文件内容保存。

最终版本为控制 `0.3.2-secrets-v1-aab221c3c29cb302`、Guard/Relay `guard-v1-75d02119f7c7f317`，沿用 R5A r6 浏览器。最终 checks 镜像通过 226 项，加密备份 28 项、QA 挂载 11 项通过，Relay Go test/race/vet 通过；真实运行 18 项（含三协议 35 项网络检查）、加密新环境恢复和 6,472 文件凭据扫描均通过。详见 [R5B 验收](../../infra/sealskin/secret-store-acceptance-2026-09-14.md)，本机根目录 `infra/sealskin/runtime/r5b-secret-store-2026-09-14/`，最终构建为 `build-v2`。早期脚本失败与各次重跑结果分别保留，不把历史目录整体标为通过。
