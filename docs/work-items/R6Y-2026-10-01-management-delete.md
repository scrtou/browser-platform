# R6Y · 代理、指纹数据与访问账号删除

状态：已收尾并部署（2026-10-01）；前项 R6X 已收尾。

## 范围与代码地图

用户要求三个管理页提供删除能力。实际 UI/后端均缺：代理仅停用/撤销，来源模板/组合/作业只增不减，账号仅禁用/改角色。此为新工作，不属于把既有失败降为通过。

- 网络代理：按页面中的精确代理修订删除；在 networkProfilesMu 下检查所有当前浏览器引用，先撤销凭据再写不可变删除审计，隐藏该修订；保留编号与历史防止凭据版本复用。引用不为零拒绝，不隐式停止浏览器。
- 指纹/显示来源：持久删除标记使其退出列表和新作业选择，原来源字节与生成证据保留；内置显示不可删除。已受理任务和既有组合保持；按用户补充要求，通过全部保留作业追溯浏览器的间接引用，有引用拒绝删除。
- 已验收组合：精确三元组退出新建/普通重选列表，保留既有浏览器绑定、启动校验和历史回退。与创建/模板应用串行；当前绑定、未完成创建/模板更新或浏览器回退历史引用时均拒绝，防止破坏重试。
- 验收任务：只删除已结束任务的列表记录，不删除队列/状态/产物；运行和排队任务拒绝，输出被浏览器引用也拒绝。不把删除任务等同于删除已发布组合。
- 访问账号：在原注册表文件锁内删除账号，禁止当前操作者自删和最后启用管理员删除，Reload 撤销目标登录/显示授权；不停止远程浏览器、不删除 Home。

入口为管理页 POST → httpapi handler → AccountStore / Profile service → 原子目录或私有删除标记；凭据撤销复用既有加密控制器调用。模板标记放 spool/templates/deleted，runner 原文件/哈希不改；查标记故障拒绝新选择。管理动作仍需要管理员/CSRF/Origin/近期确认密码，并有页面确认步骤。

已有大量未提交改动保留，基于 R6X 冻结 Adapter 做最小发布；控制器/runner 不更新，R6I/R7G 不发布。私有证据 `infra/sealskin/runtime/r6y-management-delete-20261001/`。
