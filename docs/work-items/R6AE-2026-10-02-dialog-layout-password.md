首页/管理页修改密码入口打开同一弹窗，原/auth/password保留无脚本回退。密码提交在弹窗反馈当前密码错误/确认不匹配/成功，保留CSRF、限流、当前密码验证及原其他登录撤销语义。新增/重置/自助修改/CLI共用密码哈希入口最低4、最高256字节，不改变哈希强度；前端提示/字节校验与后端一致。
