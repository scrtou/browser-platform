## 实施与偏差

已选用本机模型标识 `gemini-3.8-flash-high`。给模型的实现范围以 [UI 重构说明](../management-ui-redesign.md) 为唯一视觉契约，并要求先检查当前模板和测试、只使用 `apply_patch`、不得部署或修改真实状态。`agy` 前两次分别因参数顺序和无头读取许可未开始工作；第三次在本任务范围内启用工具许可后完成模板与 DOM 契约测试编辑。它的后台测试等待未正常返回，主流程终止等待并独立执行全部验证。

实现把九列浏览器表格改为按 Profile 分组的响应式卡片，增加语义顶栏/主区域/页脚、状态徽标、入口和概览网格、带可见标签的表单、生命周期操作、高级网络折叠区与独立危险区；指纹作业和账号表放入局部滚动容器。未增加 JavaScript 或外部资源。既有测试发现环境产物下拉框属性顺序改变导致稳定片段不兼容，已恢复 `name` 首属性并通过原测试，没有放宽旧断言。基准与候选模板的字段名、表单 action 集合核对无增减。

偏差文件链接：经核对未发现需要改变业务设计的偏差。隔离视觉检查受本机浏览器环境限制，不属于实现偏差，按未验证范围保留：第一次直接无头截图因图形缓冲初始化失败，第二次经镜像内 Playwright 启动仍阻塞；均未生成截图。精确临时容器、预览 HTML、空输出目录和临时测试辅助文件均已清理，生产容器未修改。
