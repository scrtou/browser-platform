## 入口与布局

顶级导航为“浏览器 / 网络代理 / 指纹数据 / 访问账号”，沿用原有能力门控。“指纹数据”内设置三个原生链接导航，按 1 指纹模板、2 显示模板、3 组合验收排列。选中项使用背景、边框和 aria-current 同时标识；每次只渲染当前功能，浏览器前进后退和禁用脚本均可正常使用。整体沿用现有浅灰背景、白色面板与蓝色操作按钮，不增加前端依赖。

| 功能 | 内容与操作 |
| --- | --- |
| 指纹模板 | 创建名称、语言列表和时区；下方表格列出已保存来源。明确模板保存后还需组合验收；来源不直接作为新增浏览器的完整环境。 |
| 显示模板 | 内置自动分辨率与自定义固定显示统一表格；折叠固定屏幕/窗口/DPR 创建表单。内置模板只读，自定义规则保持。 |
| 组合验收 | 选择指纹、引擎和显示模板，提交生成并验收；展示任务进度/结果和已验收组合。完整组合标明引擎/版本、语言/时区、显示和新建资格，便于对应新增浏览器选项。 |

R6AC将创建/生成表单默认折叠，来源、显示、任务及组合统一列表；长名称、语言和标识可换行，手机表格仅在自己的容器滚动。每个表单有明确的 label，原字段与校验限制保持；详细 ID/摘要可放原生 details，避免占据主要操作区。

## 导航与反馈

规范地址为 `/manage/?tab=fingerprint-data&section=fingerprints|displays|combinations`；缺省或未知 section 回指纹模板。旧 `tab=fingerprints/displays/jobs` 分别映射到三个功能。保存指纹/显示返回对应功能，提交组合与旧作业返回组合验收，成功/失败 notice 均保留。确认密码 next 从同一白名单状态生成，不接收任意外部返回地址。

空来源显示创建提示并提供内部跳转；组合入口仍展示引擎和内置显示，缺少指纹/显示/引擎时禁用提交并说明原因。没有任务或验收组合时分别显示空状态。目录读取失败维持明确不可用响应，不伪造空目录或通过状态。

## 安全与验证

只重组服务端模板和导航，所有 accepted 检查、来源保存、队列、CSRF/Origin/管理员权限、nonce CSP 和 R6U 新建联动保持。模板转义动态文本，指纹数据列表与折叠创建无需新增脚本，页面保留统一侧栏nonce脚本；不持久化客户端状态。

验证三功能路由/旧入口/默认/未知值、表单字段与返回、权限和错误边界；真实浏览器检查 1280/768/390、多来源/显示/三引擎/任务与完整组合、空状态、键盘、禁用脚本、刷新与前后导航。目标 Mac/Trilium 实机结果独立记录。
